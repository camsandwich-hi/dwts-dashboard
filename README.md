# Dancing with the Data 🪩

An interactive Dancing with the Stars statistics dashboard.

## Technologies
- Python
- Streamlit
- Pandas
- Plotly
- Google Cloud Run

## Features
- Historical DWTS results
- Professional dancer statistics
- Judges' score comparisons
- Interactive season filters

## Run Locally
pip install -r requirements.txt
streamlit run app.py

## Project Goals

This project explores historical Dancing with the Stars data
through an interactive dashboard built with Python and Streamlit.

The dashboard will allow users to:
- Explore contestants across 34 seasons
- Compare professional dancers and their Mirrorball wins
- Analyze judges' scores and final placements
- Explore estimated fan support and voting trends

The project is being developed as part of a cloud computing
course and will eventually be deployed to a cloud platform.
